자기소개

01 · 지원 동기

안정적으로 운영되는 서비스와 AI 에이전트를 만드는 개발자

기능을 구현하는 것에 그치지 않고, 실제 사용자가 불편 없이 이용할 수 있는 서비스를 만들고 싶습니다. 군 복무 중 신병교육대 교관으로 근무하며 인원 관리, 교육 준비, 일정 조율을 담당했고, 작은 누락 하나가 전체 일정에 영향을 줄 수 있다는 점을 경험하며 맡은 일을 정확하게 확인하는 태도를 갖게 되었습니다.

이후 LastCall, WorkLog, GestureOS, JE-Trace 프로젝트를 진행하며 모바일·웹 서비스 구현, 공공 API 연동, 권한 관리, 데이터 처리, 배포와 테스트를 경험했습니다. 현재는 Python과 AI 에이전트 기술을 학습하며 기존 서비스에 AI 기능을 안정적으로 연결할 수 있는 역량을 넓히고 있습니다.

02 · 성장 과정

한번 시작한 일은 끝까지 해내는 태도

처음 맡은 업무라도 필요한 절차를 익히고, 반복해서 확인하며 역할을 수행해왔습니다. 개발을 배울 때도 같은 방식으로 접근해, Java, Spring Boot, React, MySQL을 학습하며 오류가 발생할 때마다 메시지와 데이터 흐름을 확인하고 원인을 찾아 해결했습니다. 최근에는 Python, LLM API, 프롬프트 설계와 AI 에이전트의 작업 흐름을 학습하며 새로운 기술을 실제 기능으로 연결하는 경험을 쌓고 있습니다.

03 · 업무 수행 방식

전체 흐름을 파악한 뒤 단계적으로 해결

업무를 시작할 때는 필요한 기능, 사용자 화면, 데이터 구조와 처리 흐름을 먼저 정리하고, 작업 범위를 나누어 우선순위를 정해 핵심 기능부터 단계적으로 구현합니다. WorkLog에서는 AI 응답 처리 중 JSON 파싱 오류가 발생해 출력 형식을 고정하고 예외 처리와 오류 로그 저장을 적용했고, GestureOS에서는 손 좌표가 흔들리는 문제를 좌표 보정 로직과 기능별 상태값 분리로 해결했습니다.

04 · 성격의 장단점

책임감 있게 확인하고 마무리하는 성격

맡은 일을 책임감 있게 마무리하려는 점이 장점입니다. 화면 결과뿐 아니라 API 응답, 데이터 저장 여부, 예외 상황까지 함께 확인하려 하며, 이는 오류를 줄이고 완성도를 높이는 데 도움이 되었습니다. 다만 세부적인 부분까지 확인하다 보면 속도가 늦어질 때가 있어, 최근에는 핵심 기능을 먼저 구현·테스트한 뒤 세부 기능을 단계적으로 개선하는 방식으로 균형을 맞추고 있습니다.

05 · 입사 후 포부

빠르게 적응하고 꾸준히 발전하는 개발자

입사 후에는 회사의 업무 방식과 개발 환경을 빠르게 익히고, 화면·API·데이터베이스와 예외 상황을 함께 확인하며 실제 사용 과정에서 문제가 발생하지 않도록 하겠습니다. Python과 AI 에이전트 기술을 꾸준히 학습해 기존 서비스에 AI 기능을 안정적으로 연결할 수 있는 역량을 갖추고, 장기적으로는 시스템 전체 흐름과 유지보수, 운영 안정성까지 고려할 수 있는 개발자로 성장하겠습니다.
